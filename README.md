# Академия вкуса — кликабельный прототип

Прототип закрытого клуба (PWA): витрина, приложение клуба и админпанель. Данные демонстрационные, оплата и боты имитируются.

## Запуск

```
node serve.js
```

Откройте http://localhost:5173. Переключатель режимов (посетитель, участник, подписка закончилась, модератор, администратор, техспец, владелец) — вверху страницы.

Проверка таймера заказа: откройте http://localhost:5173/?ttl=0.3 (заказ действует 18 секунд вместо 30 минут).

## Структура

- `prototype/index.html` — приложение и админка (HTML, CSS, JS)
- `prototype/vitrina.css`, `prototype/vitrina.js` — вёрстка витрины от клиента
- `prototype/fonts/`, `prototype/img/v2/` — шрифты и изображения из нового визуала
- `serve.js` — локальный сервер без зависимостей
