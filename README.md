# Академия вкуса — кликабельный прототип

Прототип закрытого клуба (PWA) в стиле клиента: витрина, библиотека, события, чат, профиль и админпанель.
Данные демонстрационные, оплата и боты имитируются.

## Запуск

```
node serve.js
```

Откройте http://localhost:5173. Вверху страницы переключатель режимов: посетитель, участник,
участник с закончившейся подпиской, модератор, администратор, техспец, владелец.

## Структура

- `prototype/index.html` — всё приложение (HTML, CSS, JS в одном файле)
- `prototype/fonts/` — шрифты Prata и Manrope из лендинга клиента
- `prototype/img/` — фото из лендинга клиента
- `serve.js` — локальный сервер без зависимостей
